Open questions

For you or the DGM.

  1. One lane stopped: the full stringer factor (0.333), as the Excel does, or half?Half means both lanes down counts as one full stringer. In Aug–Sep, 105 of 166 stringer rows were one lane only, so this changes stringer weighted downtime by about a third.
  2. Bussing factor: one bussing serves one stringer, so should a bussing stop cost 0.333 like the stringer, not the Excel’s 0.9?Once you send the machine list, I’ll check every factor against how many of each machine a line has.
  3. Price for issues: the average price of what is in stock?The other common choice is the last purchase price, which jumps more from month to month.
